# Privacy Policy

This extension processes article content locally in your browser.

## What is stored locally

- Markdown source text
- Automatic sync preference
- Recently used themes
- Favorite themes

These values are stored in `chrome.storage.local`. They are not synced by this extension and are not uploaded by this extension.

## What is not done

- No analytics or tracking scripts.
- No remote AI API calls.
- No article publishing API calls.
- No collection of your WeChat credentials.
- No automatic mass-send or publish action.

## Network access

The extension requests host access only for:

```text
https://mp.weixin.qq.com/cgi-bin/appmsg*
```

This is required to inject the panel and write formatted content into the article editor.

## Contact

If you find a privacy issue, open a GitHub issue.
