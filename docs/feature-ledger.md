# 公众号排版插件 Feature Ledger

**产品代号：** WeChat Theme Switcher  
**文档状态：** v0.8.2 · Markdown 源文工作台  
**更新日期：** 2026-09-27

## 产品目标

在微信公众号编辑页内维护一份 Markdown 源文，并从这份源文一键重建正文排版。用户不需要在独立排版工具和公众号后台之间来回复制粘贴。

## 当前核心流程

```text
导入 / 粘贴 Markdown
→ 自动同步公众号正文
→ 第一个 H1 写入公众号标题
→ 点选主题
→ Markdown → 干净 HTML → 主题 HTML → 写回正文
→ 用户使用公众号自己的保存草稿
```

## 0.9 Must Have

1. 真实公众号草稿完整回归。
2. 标题输入框识别失败时的显式提示与兜底。
3. 检测公众号正文被手动编辑后的冲突提示。
4. 长文章性能、撤销 / 重做、保存刷新回归。
5. 移除生产包中的开发重载入口并完成商店审核提交。

## 明确不做

- 不自动群发或发布。
- 不上传文章。
- 不保存公众号登录凭证。
- 不绕过公众号图片上传机制。
